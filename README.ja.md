# PomPom

集中が続くと踊り、スマホを持つと声をかける、Reachy Mini Wirelessの相棒です。
本体からOpenAI Decisions APIへ直接接続します。共有APIやMacの常駐は不要です。

## 使い方

1. Reachy Miniのダッシュボードから、このSpaceをアプリとしてインストールし、`pompom`を起動します。
2. **http://reachy-mini.local:8043/**（または本体のIP:8043）を開きます。
3. OpenAI APIキーを登録し、カメラ確認・通知テストを行います。
4. 画像の送信間隔を設定します。初期値は60秒（1分）、1〜3600秒で変更できます。開始時に1回、その後は指定間隔で送信します。応答待ちで遅れる場合があります。
5. 「スマホ」「猫背」「自由入力」から反応する条件を複数選べます。自由入力では、カメラで見える条件を文章で入力します。
6. 集中する時間（初期値25分）を保存し、画像送信への同意後に開始します。

このSpaceは紹介・配布ページです。カメラやOpenAI APIキーをSpaceへ送る操作画面ではありません。
APIキーは利用者自身のものを本体で入力してください。API利用料金とOpenAIの保持条件が適用されます。

## 反応する条件

複数選べます。どれかの条件が観測時の画像で当てはまると反応します。条件ごとに可視性を独立して判定し、画像1枚を1回のAPIリクエストでまとめて判定します。初期値は「スマホ」です。

- **スマホ**：手に持ったスマホを対象に、観測時に当てはまれば反応します。机に置いただけのスマホは対象外です。
- **猫背**：上背部が丸まり、頭や肩が前へ出た姿勢を対象に、観測時に当てはまれば反応します。頭・肩・胴体が見えるカメラ位置で使ってください。顔のアップだけでは判定できません。
- **自由入力**：カメラで見える動き・姿勢を1000文字以内で入力できます。例：「顔の前で本を持っていたら反応する」。観測時に当てはまれば反応します。見えない情報や内面の状態は画像だけで判断できません。

いずれも条件の確率0.8以上・可視性0.7以上が必要です。見えない・曖昧な場合は判定を保留します。条件を変更して保存すると進行中のセッションを終了し、古い判定結果を破棄します。保存後に開始し直してください。

## API使用量・推定料金の累計

操作画面に完了リクエスト回数・成功/失敗回数・入力/出力/合計トークン数を表示します。トークン数はAPI応答の`usage`を集計し、トークン数が返らない応答は別途件数を表示します。停止後に返ったAPI応答も使用量には含めます。

ドル建ての推定累計も小数6桁で表示します。[Decisions API公式料金](https://developers.openai.com/api/docs/guides/decisions#pricing-and-availability)（2026-11-05確認）で計算し、100万トークンあたり通常入力$0.10、キャッシュ読込$0.01、既定の30分書込$0.125、出力は無料です。キャッシュ分は入力トークンに含まれるため、二重に加算しません。旧版など内訳不明の入力は通常単価で概算し、その旨を表示します。使用量不明の応答は料金に含めず、件数を明示します。税・他アプリ分を含まない目安で、実際の請求額ではありません。

`~/.config/pompom/usage.json`（0600）に保存するため、セッション変更やアプリ再起動でも引き継ぎます。保存内容は累計値と集計開始日時だけで、画像・条件文・APIキーは含みません。0.2.0以降のこのアプリでの集計であり、アカウント全体の使用量や請求金額ではありません。保存に失敗した場合は画面に表示します。

## 動作

- 観測時に選んだ条件すべてが当てはまらないと明確に判定できたら、公式`dance1`で踊ります。
- ダンス中に最初のスマホ保持判定が返ったら、ダンスを中断して公式`fear1`へ切り替えます。
- 各観測で条件の確率0.8以上・可視性0.7以上なら即反応します。クールダウンはありません。
- スマホの検知による反応ではプリセット音声の後に、2種類の日本語の声かけからランダムに1つを再生します。猫背は「猫背になっているみたい。少し姿勢を戻そう。」と合成音声で知らせます。自由入力は条件文を読み上げず、汎用の声かけで知らせます。実際に複数の条件を検知した場合は、それらをまとめた声かけに切り替えます。
- 検知していた条件が解消し、選んだ条件すべてが当てはまらないと明確に判定できたら、公式`cheerful1`で1回喜びます。
- 一時停止・終了・設定変更・期限切れはローカルで先に処理し、遅延した判定を破棄します。
- 判定不能・通信失敗・設定間隔を超える判定欠落でも観測の記録をリセットし、ダンスを止めます。
- アプリが動作していれば、操作ページを閉じても本体のタイマーと観測は継続する構成です。

判定は撮影・通信・推論の速度に依存します。送信間隔が長いほど検知や解消の確認も遅くなります。
机に置いたスマホは対象外です。仕事でスマホを使う際は一時停止してください。
集中力・意図・医学的な状態を診断するものではありません。

## OpenAIへの直接接続

送信先は`https://api.openai.com/v1/decisions`に固定し、モデルは`gpt-6-luna`を使用します。
[公式Decisions APIガイド](https://developers.openai.com/api/docs/guides/decisions)に準拠します。
Decisions APIの利用権限があるAPIキーが必要です。APIエラー時は画面に状態を表示します。

JPEGはメモリ内で長辺640px以下へ縮小し、1MiB以下に制限します。画像はこのアプリでは永続保存しません。
同時判定は1件、撮影間隔は初期値60秒、1〜3600秒で変更できます。レート制限時は30秒または設定間隔の長い方だけ待機し、残高・認証・権限エラーは一時停止します。
APIキーは`~/.config/pompom/settings.json`に0600で保存し、画面へのAPI応答やログに出しません。
`OPENAI_API_KEY`環境変数は、まだ設定ファイルがないときの初期値としても利用できます。

## 操作画面が開かないとき

`ERROR - Using Python … environment at: /venvs/apps_venv`の1行だけではインストール失敗とは限りません。後続の`Successfully installed`や`Job 'install' completed successfully`を確認してください。

ダッシュボードからPomPomを起動し、本体のアドレスの**8043番ポート**を開きます。8000番のダッシュボードに接続できても、同じネットワーク経路で8043番へ接続できるとは限りません。Tailscaleを使っている場合は、本体のTailscaleアドレスに`:8043`を付けてください。`/api/status`の成功応答はアプリの初期化完了を示しますが、OpenAIによる実判定を確認したことにはなりません。

## 既存アプリとの共存

共有API版[Reachy Focus](https://github.com/aieo-product/devdayHackathon261018)とは別のアプリです。
`pompom`パッケージ・entry point、ポート8043、`~/.config/pompom/`を使用します。
既存の`reachy_focus`（ポート8042・設定`~/.config/reachy-focus/`）を削除・上書きしません。
本体のアプリ管理で、使いたいアプリを選んで起動してください。

## 開発・検証

ソースをGitでcloneする場合はGit LFSが必要です。音声素材は公開Hugging Face Spaceから取得します。
Reachyのダッシュボードからのインストールは、SDKが音声素材も取得します。

```sh
python -m pip install -e '.[dev]'
python -m pytest -q
ruff check pompom tests
python -m build
python scripts/check-package.py
reachy-mini-app-assistant check .
```

LinuxではSDKのビルドにCairo・GObjectの開発ライブラリが必要です。CIのインストール手順を参照してください。

共通API版の実装・実機で確認したモーション・音声素材を引き継いでいます。
PomPomの直接接続、判定失敗、停止後の遅延応答、タイマー、音声ヘッダーは自動テストで確認します。
本リリース時点で、PomPomからの有料OpenAI実要求と実画像認識、実機の長時間継続は未確認です。
公開したSpaceと、Reachyの標準アプリ一覧への掲載は別です。


### 判定写真と送信間隔

アクションの記録には、その判定に使った写真を小さく表示し、クリックで拡大できます。直近20件、最大512pxをメモリ内だけに保持します。ディスクへ保存せず、新しいセッションやアプリ終了で消えます。写真表示のための追加撮影・API送信は行いません。更新前のアクション写真は復元できません。

初期値は1分ごとの観測です。各観測で条件の確率0.8以上・可視性0.7以上なら即反応し、2秒・3秒の継続時間は数えません。間隔が長いほど検知や解消の確認も遅くなり、撮影していない時間の状態は判定しません。


### 合成音声の声かけ

「声かけ」は独立してオン・オフできます。「音声を再生」をオフにすると、エモーション音と声かけの両方が止まります。定型文をmacOSのKyoko音声であらかじめ合成したWAVを同梱しており、本体ではローカル再生だけを行います。音声生成APIの呼び出しや追加料金はありません。再生成手順は`scripts/generate-speech.py`です。


### 気まぐれな仕草と鳴き声

小さな首・触角の動きに加え、待機中と見守りの合間に、公式のcurious1・attentive1・inquiring1から音付きの仕草をランダムに再生します。最初は12〜25秒、その後は15〜35秒で間隔が揺らぎます。検知反応や声かけを優先し、一時停止・終了・通信エラー中や次の撮影直前には始めません。「気まぐれな仕草と鳴き声」で無効化でき、「音声を再生」をオフにすると鳴き声も止まります。状況説明の読み上げや、追加の撮影・API送信はありません。fear1とdance1の元の音はそのまま再生します。


### 無料モード

「無料で遊ぶ」で、時間無制限の待機モーション・気まぐれな仕草と鳴き声を楽しめます。APIキー・画像送信の同意は不要で、カメラ画像の取得やモデルへの要求は行いません。一時停止・再開・終了も本体内だけで行い、設定変更では無料モードを維持します。AI見守りから切り替えた際、すでに送信済みの要求の使用量が遅れて計上される場合がありますが、古い判定では反応しません。無料モード中はカメラ確認も無効です。AI設定と使用量の詳細は折りたたみ表示です。
